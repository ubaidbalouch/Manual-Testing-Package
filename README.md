# Manual-Testing-Package
Manual Testing Documentation Portfolio
A collection of sample software testing documents created to demonstrate
my understanding of manual software testing, test documentation, and
defect reporting.
Portfolio note: The documents in this repository are practice/demo
samples prepared for learning and portfolio purposes. They are not
deliverables from a real client engagement or a claim of testing a
production system.

What This Repository Demonstrates
This repository showcases my ability to prepare and organize common QA
documentation, including:
- Writing a software test plan
- Designing test cases for application functionality
- Documenting software defects in a structured bug report
- Describing test scenarios, expected results, and actual results
- Communicating testing observations clearly and consistently
